# TradeLens

**Turn a month of order history into the 2–3 trading habits that are costing you money.**

This is a take-home case for the Nubra Product Management Intern role (Problem 03: post-trade review), by Bhavya Mohnot.

- **Submission (all four artifacts in one PDF):** [`submission/TradeLens-submission.pdf`](submission/TradeLens-submission.pdf). It contains the one-pager, the prompts, the evals and the working app.
- **Live app:** https://trade-lens-omega.vercel.app/
- **Source code:** [`app/`](app/). See [`app/README.md`](app/README.md) to run, test (`npm test`), evaluate (`npm run eval`) and deploy it.
- **PDF source:** [`submission/source/`](submission/source/). Run `python3 build.py` there, then print `submission.html` to PDF.
