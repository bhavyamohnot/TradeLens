# Working app

**Live app:** _paste the Vercel URL here after deploying_ (e.g. `https://tradelens-<name>.vercel.app`)

- No login needed. It runs entirely in the browser, and uploaded files never leave the device.
- **Fastest click-through:** open the app and click **"Sample: a month of F&O order history"**. That is a synthetic September 2026 broker tradebook with raw buy/sell fills.
- **Brief's example file:** click **"Sample: closed-trade sheet"** to load `TradeLens-example.xlsx`.
- **Your own file:** upload a broker tradebook (for example Zerodha Console → Reports → Tradebook → CSV/XLSX), or any sheet with one row per closed trade.

Source code: `app/` in this folder. See `app/README.md` for how to run and deploy it.
